# Painel de Orçamentos — Segurança Pública (SSP) e Sistema Prisional (SAP)

Painel de visualização de dados **públicos** de orçamento da Secretaria de Segurança Pública e da Secretaria de Administração Penitenciária.

**No ar:** https://josemardp.github.io/Or-amento/

## Como é

Site estático de página única (`index.html`), sem build e sem dependências. Abra o arquivo no navegador para ver localmente.

## Como publicar

Editar o `index.html`, commitar e dar push na `main`.

## Escopo

Trabalha só com dado orçamentário público. **Não tem relação com o `financeiroje`**, que é o app de finanças pessoais e do MEI — são domínios diferentes que só se parecem pelo nome.
